# Portfolio Screenshot Guide

Use this checklist when capturing screenshots for a design audit. Keep browser zoom at 100% and capture clean views without developer tools open.

## Desktop Homepage

- Full first screen of the homepage hero.
- Hero text, portrait image, theme button, and animated role ticker visible together.
- A second screenshot after scrolling slightly if any hero content is near the fold.

## Mobile Homepage

- Mobile first screen at a common phone width, such as 390px or 430px.
- Check that the name, role text, portrait image, theme button, and ticker do not overlap.
- Capture one screenshot in dark theme and one in light theme if both are active.

## Work Section

- Full work section showing the main heading, subheading, rotating category cards, category tabs, and CTA button.
- Capture the active/selected state of the current category.
- Capture one screenshot after the carousel has rotated to confirm card spacing and movement.

## Project Detail Page

- Open one project from each major category if possible: Branding, Real Estate Creatives, Social Media, UI/UX, Videos, Meta Ads, and AI Generated.
- For each selected project, capture the page heading, category tabs, project description, and first full project grid.
- Open one image/video preview and capture the preview modal with the close button visible.

## About Section

- Capture the full About Me section, including summary cards and professional summary text.
- Capture the Core Expertise / Creative Capabilities section below it.
- Check both desktop and mobile alignment.

## Contact Section

- Capture the full contact block with email, phone, and Behance button visible.
- Capture mobile view to confirm buttons stack cleanly and text remains readable.

## Navbar

- Capture the navbar at the top of the homepage.
- Capture the bottom/floating navigation state after scrolling.
- Check selected/active menu state on About, Work, Skills, Experience, and Contact.

## Footer

- Capture the footer or final page section after the Contact area.
- Include any copyright, links, social/contact actions, and theme controls if visible.

## Recommended Viewports

- Desktop: 1440 x 900
- Wide desktop: 1920 x 1080
- Tablet: 768 x 1024
- Mobile: 390 x 844
- Large mobile: 430 x 932

## Audit Notes To Check

- Text should not overlap images, buttons, cards, or navigation.
- Buttons should have clear hover/active states and enough touch space on mobile.
- Images should load clearly and open in high quality inside preview.
- Theme switching should keep text contrast readable.
- Page refresh should start from the top of the page.
- Custom cursor should not block clicks or hide important UI.
